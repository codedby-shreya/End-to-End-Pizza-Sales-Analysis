# 🍕 Pizza Sales Analysis (SQL + Python + Power BI)

## 📌 Project Overview

This project focuses on analyzing pizza sales data using SQL, generating insights through Python visualizations, and building an interactive dashboard using Power BI.

The goal of this project is to extract meaningful business insights such as top-performing pizzas, revenue trends, and customer preferences.

---

## 🛠️ Tools & Technologies Used

* SQL (Data Analysis & Querying)
* Python (Pandas, Matplotlib)
* Power BI (Dashboard & Visualization)

---

## 📊 Dataset

* Dataset: Pizza Sales Data
* Format: CSV
* Contains information about orders, pizza types, revenue, and sales performance

---

## 📂 Project Structure

* **SQL Queries** → Contains all analytical SQL queries
* **Python Visualization** → Scripts used to generate charts and graphs
* **Dashboard** → Power BI dashboard file
* **Images** → Exported charts and dashboard previews
* **Data** → CSV dataset used for analysis
